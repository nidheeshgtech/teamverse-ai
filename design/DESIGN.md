## Brand & Style

This design system establishes an ultra-refined, executive-grade virtual headquarters tailored for elite digital agencies and multi-tenant corporate offices in Dubai and the wider Gulf region. The atmosphere merges sovereign prestige, precision engineering, and frictionless digital productivity. It rejects the playful, cartoonish aesthetic typical of conventional metaverses in favor of an architectural, high-fidelity command center: luminous frosted surfaces, deep slate canvas planes, and micro-luminescent emerald accents reminiscent of modern Middle Eastern architecture and luxury fintech interfaces.

The aesthetic fuses **Glassmorphism** with **High-Tech Minimalism**:
- Translucent obsidian panels with edge-lit specular borders float over real-time isometric 3D spaces.
- Spatial HUD controls appear weightless, unobtrusive, and calibrated for long work sessions without cognitive fatigue.
- Functional feedback is crisp, high-contrast, and definitive—elevating presence telemetry, encrypted communications, and spatial presence into an executive-tier digital workplace.
- Visual rhythm honors both Western geometric discipline and native Arabic typographic balance, ensuring immediate visual parity across LTR and RTL configurations.

## Colors

The palette is engineered exclusively for an immersive, high-contrast dark mode environment. The foundation is built upon deep cosmic obsidian (`#06090F`) and structured slate-navy (`#0D131F`), creating zero glare while maximizing depth perception for 3D isometric viewports.

### Functional Roles
- **Primary (`#10B981` Emerald)**: Represents vitality, active connectivity, confirmed actions, and key spatial triggers. In the Gulf context, emerald signifies prosperity, growth, and elite architectural luxury.
- **Secondary (`#0D9488` Cyber Teal / Desert Oasis)**: Used for secondary telemetry, data visualizations, active meeting rooms, and spatial HUD highlights.
- **Tertiary (`#D97706` Warm Desert Amber)**: Applied to alerts, VIP notifications, and executive-tier badges.
- **Neutral (`#090D16` Slate Obsidian)**: The baseline canvas. Tints and elevations build upward from this deep, cool foundation to keep contrast ratios above WCAG AAA for text.

### Ephemeral Presence Colors
Presence indicators must never be stylized with arbitrary branding; they are critical functional signals:
- **Online**: `#10B981` (Vibrant Emerald with subtle breathing radial glow).
- **Busy / In Meeting**: `#F59E0B` (Amber Gold).
- **Do Not Disturb**: `#F43F5E` (Rose Quartz).
- **Away / Offline**: `#64748B` (Muted Slate Steel).

## Typography

The typography pairings unify **Geist** for structural headings, HUD telemetry, and metrics with **Inter** for sustained chat and document legibility. This pairing provides clinical technical authority, tabular numerical precision, and exceptional micro-rendering on Retina screens.

### RTL & Arabic Readiness
During Arabic locale engagement, headings and structural elements seamlessly cascade to native Arabic geometric typefaces (such as Noto Sans Arabic or modern Cairo neo-grotesques), maintaining equivalent x-height, stroke weight, and optical tension without breaking horizontal boundaries.

### Numerical and Data Display
All HUD cards, active call timers, room coordinates, and latency indicators enforce OpenType tabular figures (`font-variant-numeric: tabular-nums`) using `Geist` or `JetBrains Mono` to prevent layout jitter during real-time data streaming.

## Layout & Spacing

The layout is built around a hybrid workspace viewport model: a full-bleed interactive 3D WebGL isometric canvas serves as the spatial bedrock, wrapped by floating modular HUD glass panels, dock bars, and context-triggered side sheets.

### Grid and Panel Philosophy
- **Desktop (1280px+)**: The canvas fills 100vw/100vh. A floating 12-column grid overlays the 3D canvas with 20px gutters and 32px viewport outer margins. Side panels (Chat, Office Directory, Executive Profiles) anchor to logical screen boundaries using fixed, calculated widths (`380px` to `440px`) with hardware-accelerated drawer sliding.
- **Tablet (768px - 1279px)**: Split-screen architecture where HUD panels convert to translucent stacked floating modals, preserving at least 60% of the isometric viewport touch interactive zone.
- **Mobile (< 768px)**: 3D viewport defaults to an optional, low-power mode or gives way to the high-efficiency 2D floor list. Spacing shifts to an 8-point compact rhythm with 16px page margins.

### RTL Logical Standards
All horizontal coordinates are strictly managed via logical tokens (`margin-inline-start`, `padding-inline-end`, `inset-inline-start`). Icons indicating unidirectional progress or spatial anchors flip along the horizontal axis, while 3D viewport spatial coordinates maintain true isometric orientation.

## Elevation & Depth

Visual hierarchy does not rely on opaque dropshadows; it uses optical light physics, layered glassmorphism, and perimeter specular highlights. 

### Elevation Tiers
1. **Level 0 (Floor Canvas)**: Deep Slate base `#06090F`. Zero blur, absolute spatial void for 3D room geometries and lighting rigs.
2. **Level 1 (Dock & Floating Rails)**: `rgba(13, 19, 31, 0.65)` with `16px` backdrop-filter blur. 1px solid `rgba(255, 255, 255, 0.06)` outline. Soft ambient shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.5)`.
3. **Level 2 (Panels, Chat Drawers, Cards)**: `rgba(13, 19, 31, 0.85)` with `24px` backdrop-filter blur. 1px solid `rgba(255, 255, 255, 0.08)` outline, plus an inner specular highlight on the top edge `inset 0 1px 0 0 rgba(255, 255, 255, 0.12)`.
4. **Level 3 (Modals, Incoming Calls, HUD Overlays)**: `rgba(9, 13, 22, 0.94)` with `32px` backdrop-filter blur. Rim-lit highlight tinted with subtle emerald ambience: `0 0 0 1px rgba(16, 185, 129, 0.25), 0 20px 48px -8px rgba(0, 0, 0, 0.8)`.

### Specular Edge Lighting
All floating panels use a dual-layer hairline border: a dark outer buffer and a subtle bright-gradient hairline across the top-facing edge to mimic real-world executive architectural glass.

## Shapes

The geometric architecture relies on **Level 2 (Rounded)** curvature with crisp, structural radii. This avoids overly circular or playful consumer shapes while eliminating brutalist sharp corners that feel hostile in high-tech digital workspaces.

- **Base Components (Buttons, Input Fields, Badges)**: 8px (`0.5rem`) border-radius.
- **Modular Cards, Presence HUDs, and Drawers**: 16px (`1rem`) border-radius.
- **Executive Modals & Floating Viewport Docks**: 20px to 24px (`1.25rem` to `1.5rem`) border-radius.
- **Presence Indicators & Micro Status Dots**: Strictly circular (`rounded-full` / `9999px`) to immediately convey status as an unambiguous instrument diode.

## Components

### Buttons & Action Triggers
- **Primary Action (Call, Send, Enter Office)**: Emerald core (`#10B981`) with rich dark typography (`#06090F`), subtle top inset highlight, and an ambient emerald outer drop glow (`0 0 20px rgba(16, 185, 129, 0.3)`) on hover.
- **Secondary / HUD Glass Button**: Translucent background (`rgba(255, 255, 255, 0.05)`), hairline border (`rgba(255, 255, 255, 0.1)`), light text (`#F8FAFC`). Hover transitions smoothly to `rgba(255, 255, 255, 0.1)` with 1px border brightening.
- **Destructive (End Call, Leave Room)**: Deep ruby translucent fill (`rgba(244, 63, 94, 0.12)`) with a rose border (`rgba(244, 63, 94, 0.35)`) and rose text (`#FB7185`).

### Presence Badges & Indicators
- Embedded directly into avatar corners with a 2px protective canvas knockout border (`#0D131F`).
- **Online**: Radiant emerald dot featuring a restrained CSS pulse ring for active live states.
- **Busy / Away / DND**: Solid color-coded dots with crisp optical contrast, completely decoupled from performance tracking metrics.

### Input Fields & Search Bars
- Background: `rgba(6, 9, 15, 0.6)`.
- Border: 1px `rgba(255, 255, 255, 0.08)`.
- Focus state: Subtle emerald halo ring (`box-shadow: 0 0 0 2px rgba(16, 185, 129, 0.35)`) with an immediate transition to border color `#10B981`. Logical padding ensures clear input text separation for both LTR and RTL cursor positioning.

### HUD Cards & Viewport Overlays
- Floating control decks (Orbit, Pan, Zoom, Room Filters) sit inside modular capsules with `backdrop-filter: blur(20px)` and soft inner shadow gradients.
- Department tags use muted jewel-tone badges (Development: Cyan, Design: Violet, Marketing: Amber, Management: Emerald).

### Executive Employee Profile Card
- Floating glass panel displaying avatar, high-res status badge, departmental badge, timezone telemetry (e.g., "Dubai GST • 14:32"), and a quick-action grid: Message, Voice Call, Video Call, Screen Share, Voice Note, and Meeting Invite.
- Action buttons are arrayed with logical flex ordering, ensuring automatic alignment flipping in Arabic view mode.
